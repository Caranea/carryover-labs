## Three-minute demonstration

Use [the current timed script](demo-script.md), which includes verified direct PDF download and source-index Meta recovery. The outline below is background for the original concept.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:20 | A small stack of entirely invented multilingual reports | Years of paper, one 20-minute appointment. Finding one test can consume the visit. |
| 0:20–0:55 | Add a synthetic report; inspect local redaction and approve | The user sees what will leave the device. A missed detail can be hidden manually. |
| 0:55–1:30 | Domain charts; unfamiliar-name matching on a real configured Meta endpoint | Different printed names become one traceable test history. Show actual latency/status; do not call a prepared screen live inference. |
| 1:30–2:05 | A deliberately uncertain reading; source viewer; checked correction | No invented decimal points or missing units. The original remains available, and a change is attributable. |
| 2:05–2:40 | Select thyroid, include unresolved readings and source references, prepare a printout | The output supports the appointment. It does not interpret the results. |
| 2:40–3:00 | Brief proof: account isolation, schema validation, source history, automated regressions | Technical depth comes from verifiable provenance and uncertainty handling. Close on the patient's benefit. |

The built-in `/demo` contains five entirely invented reports, four plotted tests and a missing-unit reading. It is an account-free prepared sample. The private photo fixture directory is unsuitable for public demo assets: replacement identities do not remove the underlying medical content.
