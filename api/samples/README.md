# Sample patient answers

`recorded.json` holds real answers from the Meta Model API for the de-identified sample patient,
Jane Doe: Muse Spark's transcription of each of her 24 document pages, and Muse Wonder's
identity of every printed test name on them. The API replays them, so "Try the sample patient"
and the demo page cost nothing, need no key and keep working when today's spending limit is
reached.

They were recorded once with `node scripts/record-samples.mjs` (paid calls, about $1–2) and are
never edited by hand. Record them again after changing the prompts, the schemas or the models.
